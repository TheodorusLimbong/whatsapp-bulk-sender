# WhatsApp Bulk Sender

Tkinter GUI to send bulk WhatsApp messages from Excel or Google Sheets, using `pywhatkit`.

## Entrypoints

- **`main.py`** — creates `WhatsAppBulkSenderApp`, calls `.mainloop()`.
- **`ui_pages.py`** — all UI logic: welcome (language selector) → source picker (Excel/GSheets) → main page (load, map columns, template, preview, send).
- **`i18n.py`** — dual language support (English / Indonesian). Contains `LanguageManager` class and string dictionaries.
- **`utils.py`** — `normalize_phone()` converts Indonesian numbers (`0xx`, `62xx`, `8xx`) to `+62` format.
- **`logic_worker.py`** — `thread_safe_askstring()` / `thread_safe_update_label()` for background-thread-safe Tkinter calls.

## Running

```
python main.py
```

## Data flow

1. Choose language (English / Indonesian) on welcome page.
2. Choose source: **Excel (.xlsx/.csv)** or **Google Sheets** (via REST API + API key).
3. Load data → auto-map columns by keyword match (`name/nama`, `phone/hp/no`, `address/alamat`).
4. Optionally select a **status column** + filter value to skip rows.
5. Set row range (`start-end`), compose template with `{name}`, `{phone}`, `{address}` placeholders.
6. Preview 5 rows, then **Start Sending**.
7. Sending runs in a background thread; `pywhatkit.sendwhatmsg_instantly()` opens WhatsApp Web in a browser.

## Gotchas

- **Sending** requires the user to be logged into **WhatsApp Web** in the default browser.
- **`config.json`** contains a real Google Sheets API key + spreadsheet ID — **do not commit changes** or expose it. Listed in `.gitignore`.
- **First send** has a hardcoded 5-second delay (`time.sleep(5)`) to let WhatsApp Web load.
- **`PyWhatKit_DB.txt`** is auto-generated by pywhatkit (sent message log). Not meaningful to edit.
- **Placeholders** use English: `{name}`, `{phone}`, `{address}`.
